How to view locally
1. Clone the repository:
   git clone https://github.com/krishna0712-hub/Krishnaprasath.P-Portfolio.git
   cd Krishnaprasath.P-Portfolio

2. Open `index.html` in your browser, or run a simple static server:
   python -m http.server 8000

Deploy
- GitHub Pages: enable Pages for the repository (use the `main` branch / root). The site will serve the `index.html` from the repo root.
- Alternatively use Netlify/Vercel for drag-and-drop/static deploy.

Quick edit pointers
- Update personal text, contact info, or projects: edit `index.html`
- Styling changes: edit `styles.css`
- Interactions/animations: edit `script.js`
- Update/downloadable resume: replace `assets/resume.pdf`
- Update images: replace files in `assets/` and update the referenced filenames in `index.html`
